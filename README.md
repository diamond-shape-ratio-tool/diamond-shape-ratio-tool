# Diamond Shape Ratio Calculator

Diamond Shape Ratio Calculator is a browser-based educational tool for understanding the length-to-width proportions of fancy-shaped diamonds.

The calculator helps users compare diamond measurements and understand how relative proportions influence the appearance of different shapes.

## Features

- Calculate length-to-width ratios using diamond measurements in millimetres.
- Explore common fancy diamond shapes, including oval, pear, marquise, emerald and radiant.
- Learn how diamond measurements relate to face-up proportions.
- Use the calculator in a browser without creating an account.
- Access the published source code under the project's open-source licence.

## Intended Audience

Jewellery students, diamond enthusiasts, developers building educational tools and anyone interested in understanding gemstone proportions.

## Important Note

Length-to-width ratio is a proportion measurement, not a diamond cut-quality grade. It cannot independently establish optical performance, craftsmanship or overall value.
